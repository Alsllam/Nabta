## The mental shift

Writing pedagogy "for a machine" is not less humane than writing it for a teacher — it is more
honest. Every soft sentence I would have written for a teacher ("review what is fading",
"notice confusion") had to become a number somewhere: fading is `review_intervals_days`,
confusion is `min_confusions: 3` in `window_attempts: 6`. The twin-file rule is what forced it:
as soon as a rule cited a value, the value needed a field, and five values that had been living
in my head went into `policy`. The numbers are placeholders — Phase 4 and the family test will
change them — but a placeholder in a file is something you can change and measure; a sentence
in a document is not.

## Gotchas hit

- The prose cited five scheduler parameters (intervals, the confusion trigger, quick-nodes cap,
  the value list, session limits) that existed nowhere as data. Added `policy` to the skills
  file and pointed each rule at its key. The checker ignores unknown top-level keys, so it
  still passes; a later version of it should validate `policy` too.
- Five-column tables are the limit for Word portrait pages. The activity catalogue reached five
  and had to merge two rows (`number-trace` / `number-write`, `add-objects` / `sub-objects`).
- The document is ~4,300 words, longer than the charter. The scheduler rules and the catalogue
  are the reference the SRS (0.5) and the property tests (Phase 6) will cite; they stay.
- No rendering problems: `{.unnumbered}` on the revision history, four code blocks, the RTL
  summary and the three `ChildText` lines all verified by reading the `.docx` back.
